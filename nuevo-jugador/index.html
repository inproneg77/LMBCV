Alta de Jugador

Da de alta un jugador nuevo directo en el roster. No pasa por el panel de administración — es un formulario simple, no se pone lento sin importar cuántos jugadores ya haya.

Solo la primera vez: pega un token de GitHub (Settings → Developer settings → Fine-grained tokens → acceso a tu repo → permiso "Contents: Read and write"). Es el mismo token que usas en Captura Rápida — se guarda solo en este navegador.
Falta el token
Se genera solo, pero revísalo — no puede repetirse con ningún jugador existente.
